# 备课PPT生成系统 — AI代码驱动规格书

> **版本**：v1.2
> **用途**：将本目录下的规格文档输入AI编码工具（TRAE/Cursor/Copilot），可直接生成完整可运行的Python项目代码
> **基线**：基于 gen_ppt.py + ppt_parser.py 重构，修复已知缺陷，架构升级

## 变更记录
- **v1.2**：选择题答案从"inline Block自然流式"升级为"AnswerGroupBlock成对排列"——答案只允许双排/四排，绝不单排
- **v1.1**：分页架构从"固定18行计数"升级为"积木流式布局"——页满由空间耗尽决定，字号只决定行高增量

## 使用方式

1. **全部生成**：按 01→10 顺序喂给AI工具，一次生成完整项目
2. **按模块生成**：先喂 01+02+04（核心架构），再逐模块补充
3. **单模块迭代**：改某个模块时只喂对应文件夹 + 01(上下文)

## 核心架构速览

```
HTTP请求 → 参数校验 → JSON大纲解析 → 排版模板生成 → 内容分页(积木流式布局) → PPT渲染填充 → OSS上传 → 返回链接
```

**分页核心**：每个元素是带实际宽高的Block，游标从左到右从上到下排列，空间放不下就换行换页。页满由cursor_y+block.height>TEXT_BOX_HEIGHT决定，不存在"行数"概念。

**答案排版**：4个答案项包装为AnswerGroupBlock，内部由宽度决定2列(双排)/4列(四排)，绝不单排。布局引擎只看到一个带高度的普通Block。
